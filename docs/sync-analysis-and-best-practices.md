# NoteGen 同步机制问题分析与最佳实践方案

## 一、核心问题结论（精简版）

### 问题1：图片资源同步缺失（优先级：高） ✅ **已解决**

**现状**：图片同步功能已实现并集成到同步流程中。

**实现位置**：
- `src/lib/sync/image-sync.ts` - 图片同步核心模块
- `src/lib/sync/sync-push-queue.ts` (第456-473行) - 自动同步时触发图片同步
- `src/app/core/main/editor/markdown/sync/sync-button.tsx` - 手动同步时触发图片同步

**工作流程**：
1. 文档同步成功后，自动提取 Markdown 中的本地图片路径
2. 调用 `syncImagesForDocument()` 上传所有依赖图片
3. 支持 GitHub、Gitee、GitLab、Gitea、S3、WebDAV 全平台

---

### 问题2：缺乏仓库状态视图（优先级：高）

**现状**：用户无法获知工作区整体同步状态，只能看到单个文件状态。

**移动端缺陷**：
- 无全量同步按钮
- 无法批量处理文件
- 网络不稳定时更难排查问题

**PC端缺陷**：
- 仅右上角设置同步，无文档同步总览
- 文件树不显示同步状态徽章
- 无法筛选"待同步"文件

**技术债务**：
- `loadRemoteSyncFiles()` 功能简陋
- 无全局同步状态统计
- 无批量操作 API

---

## 二、最佳实践方案（实现要点）

### 方案1：图片依赖自动同步（唯一方案）

**核心策略**：将图片作为文档依赖资源，随文档自动同步，图片与 Markdown 文件保持相同目录结构。

**关键实现点**：

1. **依赖解析层**（需新建）
   - 解析 Markdown 中的 `![](./images/xxx.png)` 本地路径
   - 区分 `http://` 外链和本地图片
   - 提取图片绝对路径

2. **同步管理器增强**
   - `pushFile()` 推送文档后，自动提取图片路径
   - 调用 `pushImage()` 上传所有依赖图片
   - 使用 Git API 上传二进制文件（Base64 编码）

3. **路径一致性保障**
   - 保持文档与图片的相对路径关系
   - 远程仓库目录结构与本地完全一致
   - 图片跟随文档所在目录移动（可选）

4. **移动端适配**
   - 图片读取使用 `readFile` API
   - 网络差时支持同步中断恢复
   - 同步进度可视化

5. **PC端优化**
   - 同步进度显示（文档+图片总数）
   - 大图警告提示（>5MB）
   - 后台同步不阻塞 UI

---

### 方案2：同步仪表板（推荐实现）

**核心策略**：提供全局同步状态视图和批量操作能力。

**关键实现点**：

1. **统计信息聚合**
   - 扫描整个工作区：`totalFiles`, `syncedFiles`, `pendingUpload`, `pendingDownload`, `conflictFiles`
   - 计算最后同步时间
   - 统计各状态文件数量

2. **未同步文件列表**
   - 按状态分组：待上传 / 待下载 / 冲突
   - 显示文件路径、大小、修改时间
   - 支持单文件操作（上传/下载/解决冲突）

3. **批量操作按钮**
   - 「一键同步所有」：推送本地更新 + 拉取远程更新
   - 「仅上传待推送」：只处理 `local_newer`
   - 「仅下载更新」：只处理 `remote_newer`
   - 操作前确认，显示影响文件数

4. **移动端适配**
   - 使用 Collapsible 组件折叠分组
   - 支持下拉刷新状态
   - 批量操作使用异步任务，支持后台运行

5. **PC端优化**
   - 文件树右键菜单增加「同步此文件」
   - 文件项右侧显示同步状态徽章
   - 支持多选文件批量同步

6. **状态实时更新**
   - 监听 `sync-push-completed` / `sync-pulled` 事件
   - 自动刷新统计信息
   - 同步中显示全局 Loading 状态

## 四、跨平台注意事项

**移动端**：
- 使用 `Promise.allSettled` 避免单文件失败影响整体
- 网络中断后支持断点续传
- 图片读取权限检查（iOS/Android）

**PC端**：
- 大文件同步使用 Web Worker 避免卡顿
- 支持拖拽上传图片
- 后台同步时任务栏图标提示

**通用**：
- 保持本地和远程路径结构一致
- 二进制文件使用 Base64 编码传输
- 同步失败时显示具体错误文件列表
